# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта
интернет-магазина книг Харуки Мураками. Основа проекта перенесена из
контрольной работы №1 (`kr1-html-css-shop`), Bootstrap не используется.

Из исходного проекта КР №1 удалён блок с музыкой (`music/spinning-cat.mp3`
и аудиоплеер в секции «Об авторе»).

## Адаптивные решения

- отдельный файл `css/responsive.css`, подключается после `css/style.css`;
- подход **Desktop First**: базовые стили в `style.css` рассчитаны на
  широкий экран, в `responsive.css` интерфейс упрощается через
  медиазапросы `max-width` (1024px → 768px → 640px → 430px);
- навигация: на мобильном экране меню скрывается за кнопку-бургер
  и открывается выпадающим списком;
- hero-блок: двухколоночная структура сворачивается в одну колонку;
- сетка карточек: 3 → 2 → 1 колонки; на небольшом мобильном экране
  карточка каталога превращается в горизонтальную композицию
  «обложка + текст»;
- каталог: фильтр уходит наверх над товарами;
- изображения: `max-width: 100%`, `srcset` + `sizes` для обложек,
  `picture` с WebP для каталога и hero-блока;
- форма заявки: две колонки на desktop, одна колонка на планшете
  и мобильном;
- таблица характеристик: горизонтальная прокрутка через `.table-wrapper`
  и карточное представление на мобильном экране;
- модальное окно: `width: min(100% - 32px, 560px)`.

## Доступность

- skip-link «Перейти к основному содержимому» на всех страницах;
- один `h1` на странице, логичная структура заголовков;
- навигация размечена через `nav` с `aria-label`;
- текущая страница помечена через `aria-current="page"`;
- видимый фокус на всех интерактивных элементах;
- у всех полей формы есть связанные `label`;
- у изображений осмысленные `alt`;
- таблица имеет `caption`, `th scope` и `data-label` для мобильного
  карточного представления;
- сообщения об успехе имеют `role="status"`;
- ARIA используется только там, где действительно нужно.

## Самостоятельные доработки

- бургер-меню на мобильном экране: открытие по кнопке, закрытие по Escape
  и по выбору пункта, состояние кнопки описывается через `aria-expanded`
  и `aria-label`;
- карточное представление таблицы характеристик на мобильном экране
  (через `data-label` и CSS);
- WebP-варианты обложек через `picture` (дополнительно к `srcset`/`sizes`);
- несколько вариантов responsive images: `srcset`+`sizes` (карточки,
  страница товара), `picture` (hero-блок, WebP-обложки);
- страница заявки предзаполняет выбранную книгу из параметра
  `?product=...` ссылки с кнопки «Оформить заявку» на странице товара;
- горизонтальная компоновка карточек каталога на небольшом мобильном
  экране;
- добавлены страницы `product.html` (карточка товара с таблицей
  характеристик) и `order.html` (полноценная форма заявки), которых
  не было в КР №1;
- исправлены ошибки исходного проекта: дублирующийся `for` у label
  комментария, опечатка `clas` в разметке, некорректные
  `data-product` у части кнопок, ширина модального окна
  `min(100% -32px, 560px)`.
